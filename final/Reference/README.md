# 场景参考与说明

[ChinjuForest_Reference.png](ChinjuForest_Reference.png) 是本次选定的《原神》镇守之森画面，1920 × 1080 像素。可见溪水、岩石、树林、蓝色植物与鸟居，作为《镇守之森·溪畔静听》的环境声设计依据。

图源：[HoYoLAB — Chinju Forest - Viewpoint](https://www.hoyolab.com/article/15209680)，发布者 **Jinxed Encounter**。使用的是该帖子第一幅场景图：[原图](https://upload-os-bbs.hoyolab.com/upload/2023/01/16/145585797/476f62f9a1f3706a52d34650247d9fd8_8781971357212830648.png)。获取与核对日期：2026 年 11 月 14 日。游戏画面相关权利归原权利方，图片仅作课程视觉参考，不列为本工程原创或 CC0 资产；转载时保留来源与游戏标识。

听者停留在溪岸，面向林间鸟居。浅溪绕石而过，构成持续底声；树冠中的微风补充轻微背景，近处叶丛偶尔沙沙作响，远处零星传来短促鸟鸣。声音以流水为主体，留出安静间隙，表现幽静、清凉、略带神秘感的林间空间。

这是针对画面的重新配声方案。鸟鸣与叶片声是创作选择，未把它们当作原游戏实际音频的采样；工程未提取或使用《原神》的音频。场景中没有设计人物动作、战斗或音乐层。
